# Customer Shopping Behaviour Dashboard

Built an interactive Customer Shopping Behaviour Dashboard in Power BI to explore customer demographics, purchasing trends, category performance, and business insights through dynamic visualizations.

## Tools Used
- Power BI
- SQL
- Python (Pandas)
- VSCode [Jupyter Notebook]

## Dashboard Features
- KPI Cards
- Category-wise Sales Analysis
- Customer Age Group Analysis
- Subscription Status Analysis
- Interactive Filters (Gender, Category, Shipping Type)

## Files Included
- `customer_shopping_behavior.csv` – Dataset
- `cleaning.ipynb` – Data Cleaning
- `queries_customer.sql` – SQL Queries
- `Customer_Shopping_Behaviour.pbix` – Power BI Dashboard

## Key Insights
- Clothing is the top-performing product category.
- Middle-aged customers contribute the highest purchase amount.
- Most customers are non-subscribers.
- Interactive filters help explore customer shopping patterns.
